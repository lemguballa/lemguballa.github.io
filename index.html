How I make ads with AI

AI speeds up the parts of production that used to need a crew. Taste and timing still decide whether an ad works, so every cut is finished by hand.

  1. Start with the offer

    Write several hooks for the product, then pick the strongest before opening a timeline.

  2. Script and shot list

    Draft scripts and prompts with Gemini or ChatGPT, then rewrite them in a natural, creator-style voice.

  3. Generate what is hard to film

    Create AI b-roll, product shots and voiceover for scenes that would be slow or costly to shoot.

  4. Edit for pace

    Cut tight, add captions and sound, and make sure the first three seconds earn the next ten.

  5. Export and test

    Deliver 9:16, 1:1 and 16:9 versions with hook variants so the team can test what performs.
